# Installation Guide

This guide covers installing development toolchains for building and maintaining Nexium Media client websites and applications.

## 1. Install Node.js & Package Managers

We standardize on **Node.js 22 LTS**. We recommend managing Node versions using `fnm` or `nvm`:

<Tabs items={["npm (Standard)", "pnpm (Fast)", "Homebrew (macOS)"]}>
  <Tab value="npm (Standard)">
  ```bash
  # Check Node version
  node -v
  # Should output v20.x or v22.x

  # Update npm to latest
  npm install -g npm@latest
  ```
  </Tab>
  <Tab value="pnpm (Fast)">
  ```bash
  # Enable pnpm via corepack
  corepack enable
  corepack prepare pnpm@latest --activate

  # Verify version
  pnpm --version
  ```
  </Tab>
  <Tab value="Homebrew (macOS)">
  ```bash
  # macOS Homebrew install
  brew install node@22
  brew install pnpm
  ```
  </Tab>
</Tabs>

## 2. Install the Nexium Developer CLI

The Nexium CLI provides commands for scaffolding client websites, synchronizing database models, and generating SEO sitemaps:

```bash
npm install -g @nexium/cli
```

Verify your installation:

```bash
nexium --version
nexium auth status
```

<Callout type="tip">
Run `nexium doctor` to automatically verify local dependencies, image optimization libraries, and environment variables.
</Callout>

## 3. Clone Repository

Clone your assigned client website or platform repository:

```bash
git clone git@github.com:nexium-media/client-project.git
cd client-project
```

Install workspace dependencies:

```bash
npm install
```

Proceed to the [First-Time Setup](/docs/getting-started/first-time-setup) guide to configure local `.env` variables and start development servers.
