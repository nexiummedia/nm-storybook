# Getting Started

Welcome to the Acme developer onboarding portal. This guide walks you through setting up your local development environment, obtaining necessary credentials, and running your first service.

## Prerequisites

Before starting, ensure your machine meets the minimum developer environment requirements:

- **Operating System**: macOS 13+, Ubuntu 22.04 LTS+, or Windows 11 (with WSL2)
- **Node.js**: v20 LTS or v22 LTS
- **Package Manager**: `pnpm` (v9+) or `npm` (v10+)
- **Git**: v2.40+
- **Docker**: Docker Desktop 4.25+ or OrbStack

<Callout type="info">
If you are developing on Windows, we strongly recommend using WSL2 (Ubuntu) for container runtime compatibility.
</Callout>

## Setup Path

Follow the sequential onboarding steps below:

<Steps>
### Step 1: Toolchain Installation
Install Node.js, Git, pnpm, and Docker following our [Installation Guide](/docs/getting-started/installation).

### Step 2: First-Time Setup
Clone the monorepo, configure environment variables, and verify cryptographic signing keys in [First-Time Setup](/docs/getting-started/first-time-setup).

### Step 3: Architecture Exploration
Read through our [Frontend Project Structure](/docs/development/frontend/project-structure) and [Backend API Architecture](/docs/development/backend/api-structure).
</Steps>
