# Getting Started

Welcome to the Nexium Media developer and team onboarding portal. This guide walks you through setting up your local development environment, obtaining necessary credentials, and running your first client project.

## Prerequisites

Before starting, ensure your machine meets the minimum developer environment requirements:

- **Operating System**: macOS 13+, Ubuntu 22.04 LTS+, or Windows 11 (with WSL2 or PowerShell)
- **Node.js**: v20 LTS or v22 LTS
- **Package Manager**: `npm` (v10+) or `pnpm` (v9+)
- **Git**: v2.40+
- **Docker**: Docker Desktop 4.25+ or local PostgreSQL 16+

<Callout type="info">
Ensure you have registered your developer public SSH key with the Nexium Media GitHub organization before attempting to clone client repositories.
</Callout>

## Setup Path

Follow the sequential onboarding steps below:

<Steps>
### Step 1: Toolchain Installation
Install Node.js, Git, package managers, and Nexium tooling following our [Installation Guide](/docs/getting-started/installation).

### Step 2: First-Time Setup
Clone repositories, configure local environment variables, Razorpay sandbox keys, and verify local servers in [First-Time Setup](/docs/getting-started/first-time-setup).

### Step 3: Architecture Exploration
Read through our [Frontend Project Structure](/docs/development/frontend/project-structure) and [Backend API Architecture](/docs/development/backend/api-structure).
</Steps>
