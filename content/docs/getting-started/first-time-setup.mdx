# First-Time Setup

Once you have installed the prerequisites and cloned a project repository, perform the initial environment configuration before launching services.

## 1. Environment Secrets

Copy the example environment template into your active `.env.local`:

```bash
cp .env.example .env.local
```

Fill in the required local configuration parameters:

```bash title=".env.local"
# Local Application Port
PORT=3000

# Auth & Cryptography
NEXTAUTH_SECRET=development_secret_32_characters_long!
NEXIUM_API_KEY=nexium_sandbox_token_88252

# Database Connection (PostgreSQL)
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/nexium_dev"

# Razorpay Sandbox Credentials
RAZORPAY_KEY_ID="rzp_test_sampleKey"
RAZORPAY_KEY_SECRET="sampleSecretKey"

# Site Metadata
NEXT_PUBLIC_SITE_URL="https://www.nexiummedia.com"
```

<Callout type="warn">
Never commit live production credentials, client Stripe/Razorpay live keys, or AWS tokens to git. Production keys are securely provisioned via Vercel and AWS Secrets Manager.
</Callout>

## 2. Boot Local Database

We use Docker Compose to start local PostgreSQL and Redis instances:

```bash
docker compose up -d
```

Verify that the containers are healthy:

```bash
docker ps
```

## 3. Run Database Migrations

Apply database schemas and seed realistic test accounts:

```bash
npm run db:migrate
npm run db:seed
```

## 4. Start Development Server

Run the development command with Turbopack:

```bash
npm run dev
```

Visit `http://localhost:3000` in your browser. You should see the application loaded with live hot-reloading!
