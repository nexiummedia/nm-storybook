# About Us

Acme Inc. was established to solve a recurring frustration in modern software development: engineering teams spent more time configuring cloud environments and debugging boilerplate than building product value for users.

## Our Story

In early 2021, three software architects met while designing multi-region distributed systems. They noticed how disconnected developer tools had become—documentation was stale, API contracts broke quietly between teams, and onboarding new engineers took months.

They set out to build a unified developer ecosystem that combines automated workflows, resilient backend microservices, and design-system-first frontends.

<Callout type="info">
Headquartered in San Francisco with remote hubs in London, Tokyo, and Berlin, Acme operates as an asynchronous-first workplace.
</Callout>

## Milestones

<Steps>
### 2021: Company Founded
Closed \$3.5M Seed round. Launched initial prototype of the Acme API Gateway.

### 2022: Developer Platform Launch
Reached 500 enterprise customers and expanded core microservice suite to support edge compute.

### 2024: Series B & Global Expansion
Secured \$35M Series B funding. Scaled cross-border operations to 14 countries.

### Present: Next-Gen Autonomous Tooling
Integrating proactive AI developer tooling and automated documentation synchronization across all client libraries.
</Steps>
