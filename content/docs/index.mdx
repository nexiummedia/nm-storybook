## Core Principles

When writing or maintaining software at Acme, we adhere to four foundational pillars:

1. **User Centricity**: Every technical decision should directly benefit the end user experience, performance, or reliability.
2. **Clarity Over Cleverness**: Code is read ten times more often than it is written. Write explicit, well-typed, maintainable systems.
3. **Automate Everything**: Repetitive workflows, testing, and deployments must be automated with CI/CD pipelines.
4. **Living Documentation**: If a feature is merged without documentation, it is considered incomplete.
