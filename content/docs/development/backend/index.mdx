# Backend Overview

The Nexium Media backend architecture powers client websites, lead capture pipelines, payment gateways, and analytics dashboards.

## Architecture Characteristics

- **Serverless & Edge Routes**: API handlers deployed to edge regions for single-digit millisecond response times.
- **Transactional Data**: PostgreSQL with Prisma ORM for relational schemas (leads, clients, billing).
- **Payment Processing**: Direct integration with Razorpay for Indian domestic transactions and Stripe for international accounts.
- **Reliable Webhooks**: Automated idempotent handling for lead notifications and payment status updates.
