# Backend Overview

The Acme backend infrastructure is composed of high-throughput services communicating via asynchronous event streams and synchronous gRPC/REST APIs.

## Architecture Characteristics

- **Stateless Services**: All microservice containers are stateless to allow horizontal auto-scaling in Kubernetes.
- **Relational Integrity**: PostgreSQL with Prisma ORM handles primary transactional data.
- **High-Speed Cache**: Redis cluster handles session storage, cached read-replicas, and distributed rate limiting.
- **Idempotent APIs**: All state-modifying requests support `Idempotency-Key` headers.
