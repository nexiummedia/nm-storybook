## OWASP API Security Top 10 (2023) Mitigation Matrix

Every engineer must be intimately familiar with the OWASP API Top 10 risks and their concrete architectural mitigations:

| OWASP Risk | Threat Description | Nexium Media Mandatory Mitigation |
| :--- | :--- | :--- |
| **API1: Broken Object Level Authorization (BOLA)** | User accesses another user's resource by guessing IDs (`/users/123/invoices`). | Enforce resource ownership checks in Service layer (`resource.ownerId === req.user.id`). Never rely solely on authentication. |
| **API2: Broken Authentication** | Weak passwords, missing brute force lockout, expired or unverified JWTs. | Enforce Argon2id / bcrypt work factor 12, short-lived 15-minute access tokens, and Redis sliding-window auth rate limits. |
| **API3: Broken Object Property Level Authorization** | Mass assignment allows clients to update restricted properties (`role: "ADMIN"`). | Reject unknown fields via strict schemas (`zod.strict()` or Pydantic `extra = 'forbid'`). Never pass raw `req.body` to ORM writes. |
| **API4: Unrestricted Resource Consumption** | DoS via unbounded pagination, heavy payload sizes, or missing rate limits. | Mandatory rate limiting (`express-rate-limit`, `slowapi`), maximum pagination limits (`take <= 100`), payload caps (`10mb`). |
| **API5: Broken Function Level Authorization (BFLA)** | Regular users calling administrative API routes (`DELETE /api/v1/users`). | Router-level RBAC middleware (`requireRole(['ADMIN'])`) and declarative dependency guards. |
| **API6: Unrestricted Access to Sensitive Business Flows** | Bots spamming checkout, reserving inventory, or scraping content. | Rate limiting per IP + fingerprinting, CAPTCHA verification on public forms, idempotency keys. |
| **API7: Server-Side Request Forgery (SSRF)** | API fetches user-supplied URLs and accesses internal VPC metadata services (`169.254.169.254`). | Strict domain allowlists, private RFC 1918 IP blocking for all outbound HTTP requests. |
| **API8: Security Misconfiguration** | Verbose error stack traces in production, missing CORS configuration, default credentials. | Normalized error envelopes, disabled Swagger in production, Helmet.js security headers, CORS origin allowlisting. |
| **API9: Improper Inventory Management** | Undocumented, outdated, or unversioned API endpoints running in production. | Strict URL path versioning (`/api/v1/`), automated OpenAPI generation, and legacy endpoint deprecation schedules. |
| **API10: Unsafe Consumption of APIs** | Blindly trusting data returned from third-party webhooks and microservices. | Validate all incoming third-party payloads via Zod/Pydantic schemas and verify HMAC-SHA256 signatures. |
