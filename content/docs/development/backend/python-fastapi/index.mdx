FastAPI is Nexium Media's primary framework for building high-throughput asynchronous APIs, data-intensive microservices, scientific computing backends, and AI/ML model orchestration services.

Combining native Python 3.12+ type hints with Pydantic v2's ultra-fast Rust-based validation core and the ASGI `uvicorn` runtime, FastAPI achieves raw performance comparable to Go and Node.js while maintaining clean Python developer ergonomics.

---

## The Nexium Media FastAPI Stack

Our production FastAPI services standardize on a modern, fully asynchronous ecosystem:

- **Runtime & Language**: Python 3.12+ running on `uvicorn` with `uvloop`.
- **Validation & Serialization**: Pydantic v2 (`BaseModel`, `Field`, custom model validators).
- **ORM & Data Persistence**: SQLAlchemy 2.0 (`AsyncSession`, declarative mappings) + `asyncpg`.
- **Database Migrations**: Alembic with autogenerated async revision scripts.
- **Testing**: Pytest + `pytest-asyncio` + `httpx.AsyncClient`.
- **Code Quality**: Ruff (linter & formatter) + Mypy (strict static type checker).

## 10-Line Minimal FastAPI Application

A complete, self-documenting FastAPI service with automatic Swagger UI at `/docs`:

```python title="app/main.py"
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI(title="Nexium Media Core API", version="1.0.0")

class HealthResponse(BaseModel):
    status: str
    version: str

@app.get("/health", response_model=HealthResponse, tags=["Health"])
async def get_health() -> HealthResponse:
    return HealthResponse(status="ok", version="1.0.0")
```

Run locally:
```bash
uvicorn app.main:app --reload --port 8000
```
Open `http://localhost:8000/docs` in your browser to inspect interactive OpenAPI documentation.
