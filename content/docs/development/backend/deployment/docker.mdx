# Docker Containerization

Containers provide immutable, deterministic runtime environments that eliminate the classic "it works on my machine" discrepancy. At Nexium Media, all services build as minimal, multi-stage Docker images adhering to enterprise security baselines.

---

## 1. Node.js (Express & TypeScript) Production Dockerfile

Our Node.js images use Alpine Linux, utilize multi-stage builds to avoid shipping compilers or development dependencies in the final image, and execute under an unprivileged `nodejs` user.

```dockerfile title="Dockerfile (Node.js)"
# Stage 1: Dependency resolution
FROM node:20-alpine AS deps
WORKDIR /app
COPY package*.json ./
RUN npm ci

# Stage 2: Compilation / Transpilation
FROM node:20-alpine AS builder
WORKDIR /app
COPY --from=deps /app/node_modules ./node_modules
COPY . .
RUN npx prisma generate
RUN npm run build
# Prune devDependencies to keep final image tiny
RUN npm prune --production

# Stage 3: Minimal Production Runtime
FROM node:20-alpine AS runner
WORKDIR /app

ENV NODE_ENV=production
ENV PORT=4000

# Security: Create and run under non-root system group & user
RUN addgroup --system --gid 1001 nodejs && \
    adduser --system --uid 1001 appuser

# Copy pruned production dependencies, generated Prisma client, and compiled JS
COPY --from=builder --chown=appuser:nodejs /app/node_modules ./node_modules
COPY --from=builder --chown=appuser:nodejs /app/dist ./dist
COPY --from=builder --chown=appuser:nodejs /app/package.json ./package.json

USER appuser

EXPOSE 4000

CMD ["node", "dist/server.js"]
```

## 2. Python (FastAPI) Production Dockerfile

FastAPI images leverage Python `slim` variants, compile C-extensions in a build stage, and serve applications with high-concurrency Uvicorn workers behind a dedicated non-root user.

```dockerfile title="Dockerfile (FastAPI)"
# Stage 1: Build dependencies with compiler toolchain
FROM python:3.12-slim AS builder

WORKDIR /build

RUN apt-get update && apt-get install -y --no-install-recommends \
    build-essential \
    libpq-dev \
    && rm -rf /var/lib/apt/lists/*

COPY requirements.txt .
RUN pip install --no-cache-dir --prefix=/install -r requirements.txt

# Stage 2: Minimal Runtime Image
FROM python:3.12-slim AS runner

WORKDIR /app

# Install minimal dynamic runtime libraries (e.g. libpq for postgres)
RUN apt-get update && apt-get install -y --no-install-recommends \
    libpq5 \
    curl \
    && rm -rf /var/lib/apt/lists/*

# Security: Run as non-root user
RUN addgroup --system --gid 1001 appgroup && \
    adduser --system --uid 1001 --ingroup appgroup appuser

# Copy installed Python packages from builder
COPY --from=builder /install /usr/local

COPY --chown=appuser:appuser . /app

USER appuser

ENV PYTHONUNBUFFERED=1
ENV PYTHONDONTWRITEBYTECODE=1
ENV PORT=8000

EXPOSE 8000

CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000", "--workers", "4"]
```

## 3. Strict `.dockerignore` Configuration

Prevent build contexts from uploading gigabytes of local artifacts, secrets, or node_modules:

```text title=".dockerignore"
.git
.github
node_modules
dist
build
.venv
__pycache__
*.pyc
*.pyo
.env
.env.*
!.env.example
coverage
.pytest_cache
*.log
```

## 4. Local Multi-Service Development: Docker Compose

Developers spin up isolated databases, Redis caches, and mock email utilities using a single command:

```yaml title="docker-compose.yml"
services:
  postgres:
    image: postgres:16-alpine
    container_name: nexium_postgres
    restart: always
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgrespassword
      POSTGRES_DB: nexium_dev
    ports:
      - "5432:5432"
    volumes:
      - pgdata:/var/lib/postgresql/data

  redis:
    image: redis:7-alpine
    container_name: nexium_redis
    ports:
      - "6379:6379"

  mailpit:
    image: axllent/mailpit:latest
    container_name: nexium_mailpit
    ports:
      - "1025:1025" # SMTP
      - "8025:8025" # Webmail UI

volumes:
  pgdata:
```

```bash
# Start all backing services in background
docker compose up -d

# Stop all services and tear down containers
docker compose down
```
