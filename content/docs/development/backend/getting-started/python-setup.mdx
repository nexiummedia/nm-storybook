## 1. Python Runtime & Version Management

All Nexium Media Python services require **Python 3.12 or newer**. Python 3.12 introduces substantial performance improvements in the interpreter, optimized dictionary lookups, better error tracebacks, and enhanced type parameter syntax (PEP 695).

### Version Locking with `pyenv`

```bash
# Install Python 3.12
pyenv install 3.12.3

# Set local directory version
pyenv local 3.12.3

# Verify active version
python --version   # Python 3.12.3
```

Commit a `.python-version` file at the root of the project:

```text title=".python-version"
3.12.3
```

## 2. Virtual Environment Setup

Isolate project dependencies by generating a local virtual environment named `.venv`.

### Creating the Environment

```bash
python -m venv .venv
```

### Activating the Environment

<Callout type="note">
Always verify your shell prompt displays `(.venv)` prior to executing package installations or server commands.
</Callout>

```bash
# On macOS and Linux (bash/zsh):
source .venv/bin/activate

# On Windows (PowerShell):
.venv\Scripts\Activate.ps1

# On Windows (Command Prompt):
.venv\Scripts\activate.bat
```

Ensure `.venv` is included in `.gitignore` to prevent committing virtual environment binaries to version control:

```text title=".gitignore"
.venv/
__pycache__/
*.py[cod]
*$py.class
.pytest_cache/
.mypy_cache/
.ruff_cache/
htmlcov/
.coverage
dist/
build/
.env
```

## 3. Dependency Management: `pyproject.toml` Standard

Nexium Media standardizes on **`pyproject.toml`** (PEP 621) over legacy `requirements.txt`. It unifies project metadata, dependencies, and linter configurations in a single file.

```toml title="pyproject.toml"
[project]
name = "nm-fastapi-service"
version = "0.1.0"
description = "Production FastAPI microservice at Nexium Media"
readme = "README.md"
requires-python = ">=3.12"
dependencies = [
    "fastapi[standard]>=0.111.0",
    "pydantic[email]>=2.7.0",
    "pydantic-settings>=2.2.0",
    "uvicorn[standard]>=0.30.0",
    "sqlalchemy[asyncio]>=2.0.30",
    "asyncpg>=0.29.0",
    "alembic>=1.13.0",
    "python-jose[cryptography]>=3.3.0",
    "passlib[bcrypt]>=1.7.4",
    "httpx>=0.27.0",
    "python-dotenv>=1.0.1",
    "structlog>=24.1.0",
]

[project.optional-dependencies]
dev = [
    "pytest>=8.2.0",
    "pytest-asyncio>=0.23.0",
    "pytest-cov>=5.0.0",
    "httpx>=0.27.0",
    "ruff>=0.4.0",
    "mypy>=1.10.0",
    "types-passlib>=1.7.7",
    "types-python-jose>=3.3.4",
]

[build-system]
requires = ["setuptools>=61.0"]
build-backend = "setuptools.build_meta"

# Ruff Configuration (Replaces Black, Flake8, and isort)
[tool.ruff]
line-length = 100
target-version = "py312"

[tool.ruff.lint]
select = [
    "E",    # pycodestyle errors
    "W",    # pycodestyle warnings
    "F",    # pyflakes
    "I",    # isort
    "B",    # flake8-bugbear
    "C4",   # flake8-comprehensions
    "UP",   # pyupgrade
    "ARG",  # flake8-unused-arguments
]
ignore = ["E501"] # Line length handled by formatter

[tool.ruff.format]
quote-style = "double"
indent-style = "space"

# Mypy Static Type Checker Configuration
[tool.mypy]
python_version = "3.12"
strict = true
warn_return_any = true
warn_unused_configs = true
disallow_untyped_defs = true
disallow_incomplete_defs = true
check_untyped_defs = true
no_implicit_optional = true
warn_redundant_casts = true
warn_unused_ignores = true

[[tool.mypy.overrides]]
module = ["jose.*", "passlib.*"]
ignore_missing_imports = true

# Pytest Configuration
[tool.pytest.ini_options]
minversion = "8.0"
addopts = "-ra -q --strict-markers"
asyncio_mode = "auto"
testpaths = ["tests"]
```

### Installing Dependencies

Install the project in editable mode with development tooling:

```bash
pip install -e ".[dev]"
```

<Callout type="tip">
For modern development speed, engineers are encouraged to use **`uv`** by Astral (`pip install uv`). Running `uv pip install -e ".[dev]"` completes environment synchronization up to 10-100x faster than traditional pip.
</Callout>

## 4. Environment Variables (`.env.example`)

FastAPI services load settings via `pydantic-settings` from an `.env` file. Provide a strictly structured `.env.example`:

```bash title=".env.example"
# Application Environment
ENVIRONMENT=development
PORT=8000
HOST=0.0.0.0
APP_NAME="Nexium Media Core API"
LOG_LEVEL=INFO

# Database Connection (Async PostgreSQL)
DATABASE_URL="postgresql+asyncpg://postgres:postgres@localhost:5432/nm_fastapi_db"

# Security & Secrets
SECRET_KEY="generate-a-strong-random-hex-key-here"
ALGORITHM="HS256"
ACCESS_TOKEN_EXPIRE_MINUTES=15
REFRESH_TOKEN_EXPIRE_DAYS=7

# CORS Allowed Origins (Comma-separated)
ALLOWED_ORIGINS="http://localhost:3000,http://localhost:5173"

# Third-Party Integrations
REDIS_URL="redis://localhost:6379/0"
```

## 5. Daily Development CLI Commands

Keep these primary commands in active rotation during FastAPI development:

```bash
# 1. Start local hot-reloading development server
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# 2. Run Ruff format and lint checks
ruff format .
ruff check . --fix

# 3. Run static type analysis with Mypy
mypy app

# 4. Run automated test suite with coverage
pytest --cov=app --cov-report=term-missing

# 5. Execute database migrations with Alembic
alembic revision --autogenerate -m "create users table"
alembic upgrade head
```
