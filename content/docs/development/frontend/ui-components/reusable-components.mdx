Building a reliable design system for a 100+ developer organization requires strict separation between reusable visual primitives and domain-specific feature components. A reusable component must be completely agnostic of business logic, flexible enough to fit unforeseen layouts through composition, and resilient against class conflicts.

This guide details our variant system architecture with `cva`, the `cn()` class merging utility, component deprecation lifecycles, and automated variant verification.

## The `cn()` Utility: Class Merging Done Right

When consuming utility-first styling with Tailwind CSS, naive string concatenation (`className + " " + customClass`) leads to specificity collisions:

```tsx
// Anti-Pattern: String concatenation creates competing classes
const baseClass = "p-4 text-blue-500";
const overrideClass = "p-2 text-red-500";
const combined = `${baseClass} ${overrideClass}`;
// Result: Both "p-4" and "p-2" exist in classList; CSS rule order dictates winner, NOT class order!
```

Nexium Media standardizes on the `cn()` helper, combining `clsx` (for conditional expressions) with `tailwind-merge` (for resolving Tailwind class conflicts):

```typescript
// lib/utils.ts
import { clsx, type ClassValue } from "clsx";
import { twMerge } from "tailwind-merge";

/**
 * Combines conditional class names and resolves conflicting Tailwind CSS rules.
 */
export function cn(...inputs: ClassValue[]): string {
  return twMerge(clsx(inputs));
}

// Example resolution:
cn("p-4 text-blue-500", "p-2 text-red-500");
// Correct Result: "p-2 text-red-500" (p-4 is intelligently discarded)
```

## The Variant System: `class-variance-authority` (CVA)

We mandate `cva` for all primitive components requiring style variations. Below are canonical implementations of our `Badge` and `Alert` primitives:

### 1. `Badge` Primitive Implementation

```tsx
// components/ui/Badge.tsx
import * as React from "react";
import { cva, type VariantProps } from "class-variance-authority";
import { cn } from "@/lib/utils";

export const badgeVariants = cva(
  "inline-flex items-center rounded-full border px-2.5 py-0.5 text-xs font-semibold transition-colors focus:outline-none focus:ring-2 focus:ring-offset-2 select-none",
  {
    variants: {
      variant: {
        default: "border-transparent bg-slate-900 text-white hover:bg-slate-800",
        secondary: "border-transparent bg-slate-100 text-slate-900 hover:bg-slate-200",
        destructive: "border-transparent bg-red-600 text-white hover:bg-red-700",
        outline: "text-slate-950 border-slate-200",
        success: "border-transparent bg-emerald-100 text-emerald-800",
      },
      size: {
        sm: "text-[10px] px-2 py-0",
        md: "text-xs px-2.5 py-0.5",
        lg: "text-sm px-3 py-1",
      },
    },
    defaultVariants: {
      variant: "default",
      size: "md",
    },
  }
);

export interface BadgeProps
  extends React.HTMLAttributes<HTMLDivElement>,
    VariantProps<typeof badgeVariants> {}

/**
 * Display compact status indicators, categorizations, or numerical counts.
 */
export function Badge({ className, variant, size, ...props }: BadgeProps) {
  return <div className={cn(badgeVariants({ variant, size, className }))} {...props} />;
}
```

### 2. `Alert` Compound Primitive Implementation

```tsx
// components/ui/Alert.tsx
import * as React from "react";
import { cva, type VariantProps } from "class-variance-authority";
import { cn } from "@/lib/utils";

export const alertVariants = cva(
  "relative w-full rounded-lg border p-4 [&>svg~*]:pl-7 [&>svg+div]:translate-y-[-3px] [&>svg]:absolute [&>svg]:left-4 [&>svg]:top-4 [&>svg]:text-slate-950",
  {
    variants: {
      variant: {
        default: "bg-white text-slate-950 border-slate-200",
        destructive: "border-red-500/50 text-red-600 bg-red-50/50 [&>svg]:text-red-600",
        warning: "border-amber-500/50 text-amber-800 bg-amber-50/50 [&>svg]:text-amber-600",
        success: "border-emerald-500/50 text-emerald-800 bg-emerald-50/50 [&>svg]:text-emerald-600",
      },
    },
    defaultVariants: {
      variant: "default",
    },
  }
);

export const Alert = React.forwardRef<
  HTMLDivElement,
  React.HTMLAttributes<HTMLDivElement> & VariantProps<typeof alertVariants>
>(({ className, variant, ...props }, ref) => (
  <div ref={ref} role="alert" className={cn(alertVariants({ variant }), className)} {...props} />
));
Alert.displayName = "Alert";

export const AlertTitle = React.forwardRef<
  HTMLHeadingElement,
  React.HTMLAttributes<HTMLHeadingElement>
>(({ className, ...props }, ref) => (
  <h5 ref={ref} className={cn("mb-1 font-medium leading-none tracking-tight", className)} {...props} />
));
AlertTitle.displayName = "AlertTitle";

export const AlertDescription = React.forwardRef<
  HTMLParagraphElement,
  React.HTMLAttributes<HTMLParagraphElement>
>(({ className, ...props }, ref) => (
  <div ref={ref} className={cn("text-sm [&_p]:leading-relaxed text-slate-600", className)} {...props} />
));
AlertDescription.displayName = "AlertDescription";
```

## Deprecation Strategy for Shared Components

When a component, prop, or variant is slated for removal, apply the two-sprint deprecation workflow:

1. **JSDoc Deprecation Tag**: Mark the deprecated symbol with `@deprecated` including clear migration steps.
2. **Development Console Warning**: Emit a console warning during development mode (`process.env.NODE_ENV !== "production"`).
3. **Grace Period**: Maintain compatibility for two sprint cycles before removing the deprecated code in the next major version.

```typescript
export interface ButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  /**
   * @deprecated Use `variant="destructive"` instead. Will be removed in v3.0.0.
   */
  isDanger?: boolean;
}
```

## Automated Variant Matrix Testing

All shared primitives must have automated unit tests verifying that all declared variants render without throwing runtime exceptions:

```tsx
// components/ui/Badge.test.tsx
import * as React from "react";
import { render, screen } from "@testing-library/react";
import { Badge, badgeVariants } from "./Badge";

describe("Badge Primitive", () => {
  const variants = ["default", "secondary", "destructive", "outline", "success"] as const;
  const sizes = ["sm", "md", "lg"] as const;

  // Test exhaustive matrix of variants and sizes
  variants.forEach((variant) => {
    sizes.forEach((size) => {
      it(`renders correctly with variant="${variant}" and size="${size}"`, () => {
        render(
          <Badge variant={variant} size={size} data-testid="test-badge">
            Status
          </Badge>
        );
        const badge = screen.getByTestId("test-badge");
        expect(badge).toBeInTheDocument();
        expect(badge).toHaveTextContent("Status");
      });
    });
  });

  it("merges custom class names without collisions", () => {
    render(<Badge className="custom-test-class">Label</Badge>);
    expect(screen.getByText("Label")).toHaveClass("custom-test-class");
  });
});
```

<Callout type="tip">
Run matrix tests for all design system primitives in continuous integration. This catches CSS string regressions before new releases are merged into the main development branch.
</Callout>
