## Architectural Conventions

### 1. Colocation
Keep styles, unit tests, and helper functions close to the components that consume them.

### 2. Path Aliases
Always use `@/` alias for root relative imports:

```tsx
import { Button } from '@/components/ui/button';
import { cn } from '@/lib/utils';
```

### 3. Server vs Client Boundaries
Structure components with pure Server Components as orchestrators, passing data down into minimal Client Components for interactivity.
