# UI Components

Acme UI components are crafted for high accessibility (WCAG AA compliant), keyboard navigable by default, and responsive across device breakpoints.

## Design Principles

- **Predictable APIs**: Standard prop names like `variant`, `size`, `disabled`, and `asChild`.
- **Theme Agnostic**: Built on CSS variables (`--fd-background`, `--fd-foreground`, `--fd-primary`).
- **Composability**: Built on unstyled Radix UI primitives.

## Callout Component

Callouts are used across documentation to highlight important notices, cautions, or tips:

```mdx
<Callout type="info">This is an informational notice.</Callout>
<Callout type="tip">This is a best-practice tip.</Callout>
<Callout type="warn">This is a warning regarding destructive actions.</Callout>
```

Rendered examples:

<Callout type="info">
This is an informational notice regarding system maintenance.
</Callout>

<Callout type="tip">
Use keyboard shortcut `Cmd + K` or `Ctrl + K` to summon full-text search anywhere.
</Callout>

<Callout type="warn">
Never bypass branch protection rules without explicit VP Engineering approval.
</Callout>

```typescript title="lib/auth.ts"
export async function verifySession(token: string): Promise<UserSession | null> {
  if (!token) return null;
  const payload = await jwt.verify(token, process.env.JWT_SECRET!);
  return payload as UserSession;
}
```
