# UI Components

Nexium Media UI components are crafted for high accessibility, mobile-first touch targets, and visual consistency across client websites.

## Design Principles

- **Predictable APIs**: Standard prop names like `variant`, `size`, `disabled`, and `asChild`.
- **Brand Theming**: Built on CSS variables (`--color-fd-primary: #6f00ff` for Nexium Media violet).
- **Smooth Feedback**: Interactive hover transitions, ripple states, and accessible ARIA attributes.

## Callout Component

Callouts are used across documentation and client portals to highlight essential information:

```mdx
<Callout type="info">This is an informational notice.</Callout>
<Callout type="tip">This is a best-practice tip.</Callout>
<Callout type="warn">This is a warning regarding destructive actions.</Callout>
```

Rendered examples:

<Callout type="info">
Client projects must include local business Schema.org JSON-LD structured data for Dhanbad and regional search.
</Callout>

<Callout type="tip">
Use keyboard shortcut `Cmd + K` or `Ctrl + K` to summon full-text search anywhere on the portal.
</Callout>

<Callout type="warn">
Never bypass branch protection rules or push untracked production secrets to git.
</Callout>
