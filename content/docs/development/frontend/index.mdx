# Frontend Overview

Our frontend architecture is engineered for conversion rate optimization (CRO), lightning-fast page transitions, and effortless responsiveness across every mobile screen.

## Stack & Standards

- **Framework**: Next.js App Router (React Server Components by default)
- **Styling**: Tailwind CSS with custom CSS variables for light/dark themes
- **Icons**: Lucide React
- **Forms**: React Hook Form with Zod validation
- **State**: React Query for async server state; lightweight React hooks for UI interactions
