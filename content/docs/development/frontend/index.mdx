# Frontend Overview

Our frontend architecture is engineered for performance, accessible interaction, and predictable state transitions.

## Stack & Standards

- **Framework**: Next.js App Router (React Server Components by default)
- **Styling**: Tailwind CSS with CSS custom variables for dark/light themes
- **Icons**: Lucide React
- **Validation**: Zod for client/server form validation
- **State**: Server State via React Query; lightweight local UI state via React hooks

## Quick Navigation

- **[Project Structure](/docs/development/frontend/project-structure)**: Directory layout, route handlers, and shared modules.
- **[Component Library](/docs/development/frontend/components)**: Reusable buttons, inputs, modals, cards, and design tokens.

<Callout type="tip">
Prefer React Server Components for data fetching. Only add `'use client'` at the leaf nodes that require event listeners or browser APIs.
</Callout>
