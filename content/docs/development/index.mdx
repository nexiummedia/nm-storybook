# Development Overview

At Nexium Media, we prioritize blazing-fast load times, clean modular architecture, static type safety, and seamless responsive design.

## Architecture Highlights

- **Frontend**: Next.js App Router, React 19, TypeScript strict mode, Tailwind CSS v4, Lucide React icons.
- **Backend**: Node.js microservices, Next.js API route handlers, Prisma ORM, PostgreSQL.
- **Payments & Billing**: Razorpay API integration with webhook signature validation for client bookings and subscriptions.
- **Analytics & Marketing**: Google Tag Manager, Meta Pixel, automated conversion event tracking, and Google Search Console indexing.
- **Hosting**: Edge-rendered deployments on Vercel and AWS CloudFront with automated CDN caching.

## Code Conventions

1. **Strict TypeScript**: Never use `any`. Always use explicit schemas (Zod or TypeScript interfaces).
2. **Performance Budget**: Initial JavaScript bundles must stay under 120KB per page.
3. **SEO Colocation**: Every page route must export dynamic `Metadata` with OpenGraph images and canonical URLs.
